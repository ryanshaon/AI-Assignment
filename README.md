# AI Search and Reflex Agents

A Python-based Artificial Intelligence project covering intelligent agent design, rule-based decision making, and uninformed search algorithms.

## Overview

This repository contains multiple foundational AI modules:

- Human-computer interaction test architecture
- Simple Reflex Agent for AQI classification
- BFS and DFS search for the Water Jug problem

The project focuses on understanding how AI systems read inputs, make decisions, and search through possible states to reach a goal.

## Modules

### 1. Human-Computer Interaction Test Architecture

Designed a modular architecture to explain how an interactive evaluation system can be structured.

Main components:

- User interface layer
- Server layer
- Session manager
- Response evaluation module
- Logging system
- Storage layer

### 2. AQI Simple Reflex Agent

Built a simple reflex agent that reads environmental sensor data and classifies the Air Quality Index category using rule-based logic.

Concepts used:

- Agent-percept-action cycle
- Rule-based decision making
- File input handling
- AQI category mapping

### 3. Water Jug Problem using BFS and DFS

Implemented Breadth-First Search and Depth-First Search for the Water Jug problem.

Comparison includes:

- Solution path
- Number of steps
- Nodes expanded
- Basic performance difference between BFS and DFS
